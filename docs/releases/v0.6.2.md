# PeriHub 0.6.2

## Download

**[Download Windows setup](https://github.com/Saad176/perihub/releases/download/v0.6.2/Devices-0.6.2-Setup.exe)**

One file, everything included. Run **Devices-0.6.2-Setup.exe** after downloading. No separate Python installation is required. The app and installer still use the earlier name Devices. GitHub's Source code ZIP/TAR files are for development, not installation.

## Changes

- Mouse and keyboard cards appear only when their exact supported hardware is detected.
- Unsupported mice and keyboards do not appear as an SC900 Pro or K95 Platinum.
- No supported hardware connected: a clear empty state with no device settings.
- Device list updates after plugging or unplugging hardware; the active panel switches to an available device.
- An error identifying one device no longer hides the other supported device.
- Source, tests and build scripts now live in the main PeriHub repository.

Existing DPI, polling, sensor, timing, battery and keyboard lighting controls remain included. SC900 Pro detection supports the original 8K receiver and wired USB. A receiver being present does not prove the mouse is awake; controls remain disabled until settings can be read.

## Scope

Only the AULA SC900 Pro and Corsair K95 RGB Platinum are supported. This is a personal Windows build verified on the developer's hardware, not certification for every firmware revision. The installer is unsigned. See RELEASE_STATUS.md for verification and distribution limits.
