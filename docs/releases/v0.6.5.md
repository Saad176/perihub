# PeriHub 0.6.5

**[Download Windows setup](https://github.com/Saad176/perihub/releases/download/v0.6.5/Devices-0.6.5-Setup.exe)**

## Reliability improvements

- Polling rate buttons show one selection and are disabled while a change is being verified, preventing duplicate pending changes.
- Sensor settings now use the same serialized background queue as other mouse settings. Readback must match the requested value, and connection changes are checked before writing and after verification. Results from an old connection cannot update the new connection's state.
- DPI stage 1 rejects responses belonging to another DPI stage.
- Regression coverage includes mismatched readback, connection changes, pending polling selection and switching pages during sensor writes.

Everything needed is included in the installer. Current device support and the battery estimate explanation are retained. See RELEASE_STATUS.md for hardware testing boundaries.
