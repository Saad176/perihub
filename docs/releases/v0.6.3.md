# PeriHub 0.6.3

## Download

**[Download Windows setup](https://github.com/Saad176/perihub/releases/download/v0.6.3/Devices-0.6.3-Setup.exe)**

Run **Devices-0.6.3-Setup.exe**. Everything needed is included. The app and installer still use the earlier name Devices.

## Changes

- Added a small circled information icon beside the in-app mouse battery. Hover or click for an explanation of temporary charging-related estimate changes.
- Documented a passive capture showing the mouse itself reporting 57% before USB, 66% during USB power, then returning to 57% about two and a half minutes after unplugging.

The percentage continues to show the device-reported estimate. This update adds no polling or background logging. The tray display stays concise.
