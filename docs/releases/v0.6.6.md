# PeriHub 0.6.6 ? local candidate

Not published. Prepared on the bug-fix branch for review.

Keyboard lighting preferences now survive app restarts and Windows sign-in. The app remembers effect, color, brightness and speed, and applies them when the supported keyboard is detected. Onboard selection is also remembered. Quit restores the existing onboard lighting without discarding the saved software preference.

This update saves preferences locally; it does not edit the keyboard's onboard profile. Mouse startup continues to read the device's current settings.

Verification: 58 automated regressions, including static-white restoration with the mouse panel selected, delayed keyboard connection, saved effect modes, Onboard, invalid preferences, and preservation through Quit/error.
