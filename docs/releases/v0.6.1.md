# PeriHub 0.6.1

A compact Windows tray app for the AULA SC900 Pro and Corsair K95 RGB Platinum.

## Download and install

Under **Assets**, download **Devices-0.6.1-Setup.exe** and run it. This one file bundles the application, Python, Qt and device artwork. You do not need Python, PowerShell, the AULA app, iCUE or OpenRGB installed.

The automatically generated **Source code** ZIP/TAR archives are development files, not an installer.

The project is now called **PeriHub**. This build still uses **Devices** in the app, Start menu and installer filename.

## Included

- SC900 Pro over the original 8K receiver and USB wired mode.
- Fine 50-DPI editing, 1–6 stages, stage selection and 125–8000 Hz polling.
- Sensor modes, LOD, Motion Sync, Ripple Control, Angle Snapping, debounce and dormancy.
- Mouse battery percentage in the app and tray tooltip.
- K95 lighting effects, brightness and speed controls where applicable.
- Transparent white tray icon and optional Start with Windows.
- One instance per user, background mouse commands and settings readback checks.
- Per-user installation, optional desktop shortcut and clean uninstall with preferences preserved.

Close hides the app in the tray. Right-click its icon to open it, configure startup or quit. Software keyboard effects continue in the tray; normal Quit restores onboard lighting.

## Verification and scope

40 regression tests passed, along with packaged startup, single-instance handling, graceful quit, installer update/uninstall and startup cleanup checks on the development PC. This is a personal Windows build, not certification for every PC or firmware version.

Only the two listed devices are supported. Button remapping, macros, LED/profile editing and firmware flashing are not implemented. Battery may take a few seconds to arrive, and polling changes can briefly reconnect the mouse. The installer is currently unsigned.
